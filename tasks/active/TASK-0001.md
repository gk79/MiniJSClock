- Status: blocked
- Risk: medium
- Execution profile: cloud-standard

- Required review: independent-cloud-standard
- Security impact: none

## Goal

Materialize the approved Vue + TypeScript + Vite stack in the existing Agentic SDLC repository so the repository has a minimal runnable application skeleton and deterministic local bootstrap, format, lint, type-check, unit-test, browser-smoke, security, build, verify, CI-contract, and run commands.

## Non-goals

- Do not implement world-clock product features, city catalog generation, persistence/domain behavior, alarms, or final visual design.
- Do not add Vue Router, Pinia, Tailwind, a component/UI framework, backend code, or runtime external APIs.
- Do not configure or enable the GitHub Pages deployment workflow in this task; deployment workflow permissions/release mechanics are a separate task.
- Do not replace or weaken the Agentic SDLC repository contract, `AGENTS.md`, `docs/AI_WORKFLOW.md`, task lifecycle, security baseline, or canonical Make target interface.
- Do not upgrade the approved architecture/toolchain versions merely because newer versions exist; revalidate/escalate only if an approved pin cannot be used safely.

## Escalation triggers

- Trigger: an approved direct version pin is unavailable, incompatible, or has a material security issue.
- Required action/profile: stop, record evidence, and hand off to `chatgpt-analysis` for architecture/toolchain reassessment.

- Trigger: satisfying lint/format/test/build requires a materially different framework, package manager, state library, UI library, router, backend, or deployment model.
- Required action/profile: stop and hand off to `chatgpt-analysis`; do not broaden the stack.

- Trigger: implementation requires GitHub Actions permissions, Pages environment configuration, secrets, production IAM, or other deployment trust-boundary work.
- Required action/profile: stop; defer to the separate deployment task, expected to use a stronger security-focused review contract.

- Trigger: canonical repository commands cannot be made deterministic in the target environment.
- Required action/profile: record the blocker and escalate to `chatgpt-analysis` rather than bypassing the command contract.

## Acceptance criteria

- [ ] Node/npm baseline is materialized as approved: `.nvmrc` uses Node 24.21.0; `package.json` records the Node 24 engine constraint and `"packageManager": "npm@11.19.0"`.
- [ ] Direct dependencies are pinned exactly and `package-lock.json` is committed; approved core pins from architecture are preserved.
- [ ] A minimal Vue 3 + TypeScript + Vite application runs without Router, Pinia, Tailwind, a component framework, backend code, or runtime API dependency.
- [ ] Vite production configuration supports the GitHub Pages repository base path `/MiniJSClock/`.
- [ ] The scaffold contains only a minimal product shell/smoke surface; no world-clock feature implementation is pulled into bootstrap.
- [ ] `make bootstrap`, `make format-check`, `make lint`, `make typecheck`, `make test`, `make security`, `make build`, `make verify`, `make ci`, and `make run` have deterministic stack-specific behavior.
- [ ] `make test-e2e` runs a minimal Playwright browser smoke check against the application and verifies that the root application surface renders.
- [ ] If `make test-integration` has no meaningful integration boundary yet, it returns a successful explicit `NOT APPLICABLE: <reason>` result rather than remaining a placeholder.
- [ ] No `scripts/commands/*.sh` target needed by the selected stack remains in the starter's `NOT CONFIGURED` state.
- [ ] `.vscode/extensions.json` recommends `Vue.volar`; when the executor controls the developer workstation, install/validate it, otherwise record that local installation remains a human workstation action.
- [ ] The production build contains static assets only and does not require a runtime server/backend.
- [ ] Existing Agentic SDLC documentation/tasks/harness files are preserved unless a task-required factual update is necessary.
